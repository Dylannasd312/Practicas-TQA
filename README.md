# Prácticas TQA

## Descripción

Este repositorio contiene el código base del sistema hospitalario que se utilizará como referencia para las prácticas de Testing y Aseguramiento de la Calidad (TQA).

## Tecnologías

- Laravel
- Angular
- PostgreSQL

## Objetivo

Organizar los ejercicios, prácticas y actividades desarrollados durante las clases de la materia.

## Actividades

- Ejercicios de testing.
- Diseño de casos de prueba.
- Identificación de defectos.
- Prácticas de pruebas manuales y automatizadas.
